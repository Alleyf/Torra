# 服务器看板设计系统

面板是在 Torra 的沙箱帧里打开的，不是独立网站。上一版最大的问题不是颜色不够多，而是它自建了一套 GitHub 风格的色值（`#0d1117` / `#4c8dff`），和宿主实际注入的 `#0a0b14` / `#4f7cff` 不是同一套，边框、按钮圆角和字体也各走各的，所以看起来像嵌进来的一块第三方页面。这份规范以 `src/main/plugins/panel.ts` 注入的 token 为唯一来源，面板只做派生，不再发明基础色。

第二个决定是把"读数"和"操作"分开。KPI 区域只回答"现在怎么样"，工作台回答"哪个实验、进行到哪、日志在哪"。之前把资源趋势单独铺一排卡片，和上方指标重复；现在趋势折线并进 KPI 卡片底部，省掉一整段滚动，也让每张卡自己说明变化。实验详情从行内展开改成固定的右侧检查器，点哪条都在同一块区域更新，不再把下面的内容顶走。

第三个决定是日志和文件预览不再占页面底部。它们改成右侧抽屉：打开日志时页面结构不动，关掉就回到原处；抽屉里可以暂停跟随和刷新。这样"看日志"是一个可进可退的动作，而不是把整页拉长。文件区随后从左下方一条独立横排挪进左栏、接在实验列表后面：它和实验同属"从这台机器上挑东西"，放进同一列之后右栏检查器可以从头到尾保持完整高度，页面不需要靠横向铺满来撑场面。没有选中实验时，检查器不占位置，左栏单独成立。

## 颜色

深色是默认主题，浅色由宿主切换 `data-theme="light"`。面板不写死背景，只使用变量与 `color-mix()` 派生层级。

| Token | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--p-bg` | `#0a0b14` | `#faf9f7` | 页面底色 |
| `--p-fg` | `#e8e9ee` | `#1d1f27` | 主文字 |
| `--p-muted` | `#8b90a0` | `#6b7080` | 次级文字 |
| `--p-border` | `rgba(255,255,255,.10)` | `rgba(0,0,0,.10)` | 分隔线与卡片边 |
| `--p-card` | `rgba(255,255,255,.035)` | `rgba(0,0,0,.028)` | 卡片表面 |
| `--p-accent` | `#4f7cff` | `#2f5bd7` | 选中、进度、链接 |
| `--p-warn` | `#f0b04c` | `#a86b12` | 越界、高占用 |
| `--p-danger` | `#ff6b6b` | `#c0392b` | 错误 |

派生层级只允许这几种：表面 `color-mix(in srgb, var(--p-fg) 3%, transparent)`，悬停 `4%`，分隔 `color-mix(in srgb, var(--p-border) 80%, transparent)`。强调色只出现在选中边框、进度条和实时圆点，一屏不超过三处大面积强调。

## 字体与节奏

正文 13.5px / 1.55，系统字体栈与宿主一致；数字一律 `font-variant-numeric: tabular-nums`，避免轮询时宽度跳动。等宽只用于命令、路径和日志。科学计数法留给小于 0.001 的指标（如学习率 `1.69e-4`），避免四舍五入成 0。

| 层级 | 字号 | 字重 | 说明 |
| --- | --- | --- | --- |
| 页面标题 | 20px | 650 | 只出现一次 |
| 区块标题 | 13px | 600 | 与计数、筛选同排 |
| 读数 | 26px | 650 | KPI 主数字 |
| 详情主数字 | 30px | 650 | epoch / 百分比 |
| 正文 | 12–12.5px | 400 | 不低 11px |
| 辅助 | 11.5px | 400 | 只在确实次要时使用 |
| 标签 | 10–10.5px | 500 | 大写小标签与胶囊，不超过 12 个字 |

间距用 4 的倍数：4 / 8 / 12 / 16 / 24 / 32。卡片内边距 14–18px，卡片之间 12–14px。圆角：卡片 14px，按钮/输入 9px，胶囊 999px，抽屉 0（贴边）。

## 组件

**Hero** 由左侧标题与主机信息、右侧分段标签和服务器计数组成。主机信息是单行弱文字：`gpupod · Ubuntu 22.04.5 · 128 核 · 运行 51 天`。实时状态用一个 6px 的呼吸圆点，不写"LIVE"大写装饰。

**绑定条** 是一行工具条，不是表单区块。服务器下拉、目录输入、绑定/解绑/刷新并排；已绑定时目录输入直接显示当前路径，下方一行说明绑定时间。目录输入使用等宽字体。

**KPI 卡** 顶部是小标签和状态胶囊，中部是 26px 读数，底部是两条弱文字（分项读数与更新时间）和一条 36px 迷你折线；磁盘卡用同高的占用条代替折线。CPU、内存、磁盘三张卡等宽；GPU 卡单独一行，每张含利用率、型号、显存条和 GB 数。没有 GPU 时只留一条说明，不画空卡；未绑定时整块换成一张虚线占位卡，不无限闪烁骨架。

**实验行** 是按钮语义，整行可点。左边 6px 状态点，中间名称与命令，右侧是选中箭头。名称后面跟一个等宽的 `#PID`，同名同命令的两次运行靠它分开。第二行放环境/越界/类型标签，第三行是命令（单行省略），第四行是压缩时长（`47m`、`2h12m`）、日志文件名和迷你进度条 + `6/200`；日志名吃掉剩余宽度并省略，因为它才是判断"这条曲线读的是哪个文件"的依据。多个实验写同一份日志时，标签行多一枚警告色"共用日志"胶囊。选中态用强调色左边条 + 8% 底色 + 35% 边框，不用大面积高亮。

**检查器** 固定在右列，头部是名称、状态与两个动作（打开日志、复制命令），下面是 150px 大折线、epoch 读数和预计剩余，再下面是元信息网格（PID、环境、运行时长、子进程、cwd、日志路径、日志来源）。日志来源用一句话说明这份日志是怎么认出来的（进程输出句柄 / 启动命令重定向 / 惯例文件名 / 按修改时间猜的），"猜的"和"共用"都用警告色，并在进度区上方放一张警告卡——同一份日志被两个实验写，曲线自然一模一样，界面必须先把这件事说破，而不是让人对着两条相同的线猜。未选中时给一个轻量空状态，不显示半张空图；在宽屏上它拉到与左栏同高，窄屏上直接隐藏，避免一块空卡片顶在列表下面。

**指标切换** 是可换行的胶囊，每个带阶段色点：train 蓝、valid 绿、test 橙、eval 紫。选中胶囊用强调色描边与 12% 底色。最多显示 12 个，超出就换行，不做横向滚动和右侧渐隐。

**折线** 用 1.7px 强调色线、顶部渐变面积、25/50/75% 三条虚线网格。线宽用 `vector-effect: non-scaling-stroke`，缩放不变形。读数在折线上方一行：名称、最新值、变化量，右侧是区间与点数。

**文件区** 在左栏、接在实验列表下方，是一棵目录树而不是平铺网格：根目录固定是绑定路径，子目录默认折叠，点箭头展开、再点收起，展开时才去取这一层。每行是 22px 图标 + 名称 + 次要信息，缩进按层级加 14px，行高压到 32px 左右，比原先 210px 的卡片网格更能放下长目录。头部"全部折叠"一键收回根层。整块最高 320px（窄屏 300/264px）内部滚动，任何断点都不放开高度——文件区只负责挑对象，不该靠目录深度把页面拉长。

**抽屉** 从右侧滑入，宽 `min(580px, 94vw)`，背板 48% 黑加 2px 模糊。头部是标题、刷新与关闭，副标题是路径与大小，主体是等宽文本，底部是跟随状态与"暂停跟随 / 继续跟随"。打开日志时每 2.5 秒读一次尾部；用户向上滚动超过 40px 就自动暂停跟随，点按钮恢复。焦点落在对话框本身，关闭后回到触发元素。

## 状态与动效

- 悬停：表面提亮 1–2%，边框向强调色靠 20%，120ms。
- 选中：背景 8% 强调色，左侧 3px 强调条，160ms。
- 焦点：2px 强调色外环，`outline-offset: 2px`；键盘可达。
- 加载：骨架块用 1.4s 的明暗呼吸，不用转圈文字。
- 空/错：一行标题 + 一行解释 + 可选动作，居中但不放大图标。
- 抽屉：`transform` 260ms `cubic-bezier(.2,.7,.3,1)`，背板同步淡入。
- 轮询更新不闪烁：只替换数字与路径，不重建整块 DOM 的动画。

## 不做什么

不做霓虹渐变、玻璃拟态和彩色大图标；不在 KPI 上叠加装饰性圆环；不用 9px 以下文字；不在行内展开详情导致布局跳动；不让文件区无限拉长页面；不复制宿主没有的颜色和字体。
