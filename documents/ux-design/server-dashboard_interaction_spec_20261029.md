# 服务器看板交互规格

## 信息架构

观测页分成四层，从上到下依次是：

1. Hero：面板名、主机摘要、观测/管理切换、服务器计数。
2. 绑定条：服务器选择、项目目录、绑定/解绑/刷新。
3. KPI 与 GPU：CPU、内存、磁盘三张卡，下面是 GPU 卡或一条无 GPU 说明。
4. 工作台：左栏是实验列表和它下面的项目文件，右栏是检查器。宽屏两列，窄屏按列表 → 检查器 → 文件顺序堆叠。

日志不再常驻页面，改为右侧抽屉；文件预览也用同一个抽屉。这样页面高度只由 KPI、实验数和文件目录深度决定，不会因为点开一个日志被拉到几屏长。左栏承载"挑对象"，右栏只负责"看当前这个"，两列不会互相顶动。

## 实验列表

- 整行是按钮，点击即选中，右侧检查器更新；不展开、不折叠、不顶开下面的内容。
- 首次加载自动选中过滤后的第一条实验，面板打开就有内容可看。
- 过滤条件有两层：范围胶囊（全部 / 本项目 / 有日志）和搜索框（匹配名称、命令、cwd、日志路径，大小写不敏感）。
- 过滤后如果当前选中项被隐藏，选中过滤结果的第一条；不过滤时保持原选中。
- 列表项按"绑定目录内优先、启动时间从新到旧"排序，后端已经排好，前端不再重排。
- 列表项显示：状态点、名称带 `#PID` 后缀、环境/越界/类型标签、单行命令，最后一行是压缩时长（`47m`、`2h12m`）、日志文件名和进度（迷你条 + `6/200`）；还没取到进度的写"点开看进度"，不假装在等。
- 同一份日志被多个实验写时，行里多一枚"共用日志"胶囊；悬停能看到同日志的 PID 列表。同名同命令的两个实验靠 `#PID` 与日志名区分，不靠猜。
- 计数胶囊在过滤后显示 `命中 / 总数`（如 `2 / 3 个`），不过滤时保持"3 个运行中"。
- 没有可读日志的实验仍然可选，检查器里显示原因和日志路径，并提示绑定目录后才能读。
- 列表为空、过滤为空、后端失败是三种不同空状态，各自给不同文案；过滤为空时检查器也同步说"没有匹配的实验"，不留上一条详情。

## 检查器

- 选中实验后，如果进度缓存超过 8 秒或从未取过，就发 `server.progress`；同一实验的并发请求合并。
- 切换实验立即取一次进度，不等节流窗口。
- 头部动作：`打开日志` 只在 `logReadable` 时出现；`复制命令` 始终可用，复制成功后按钮文字变成"已复制"1.4 秒。
- 进度区：`Epoch 10 / 1000`、百分比、预计剩余、6px 进度条；没有 epoch 但有 tqdm 百分比时退化为"batch 进度"。
- 指标胶囊按阶段着色，点击只切换当前图表，不重新请求；选择结果按实验 key 记住。胶囊换行而不是横向滚动，避免最后一枚被渐隐切掉。
- 图表下方给区间、点数、日志路径、读取时间和"只读尾部"标记。
- 元信息用两列网格：PID、环境、运行时长、子进程、cwd（跨两列）、日志路径（跨两列，目录外用警告色）、日志来源（跨两列）。
- 两个实验解析到同一份日志时，进度区上方先给一张警告卡：写明同日志的另一个 PID，并说明曲线来自同一个文件、分不出谁写的，附单独重定向的写法。日志是按修改时间猜出来的（`logSource: guess`）时同样给警告卡，提醒可能属于别的进程。
- 未选中时空状态在宽屏拉到与左栏同高，窄屏整块隐藏，不撑高整页。

## 项目文件

- 一棵懒加载的目录树，根目录是绑定路径；只展开用户点开的分支，子目录默认折叠，卡片高度封顶，不随目录深度把页面拉长。
- 点击目录行切换展开/折叠，展开时才发 `server.files` 取这一层；同一路径只取一次，刷新时清缓存但保留展开状态。
- 点击文件或链接行打开抽屉预览。缩进按层级递增，目录行带旋转箭头。
- 头部"全部折叠"把树收回根目录一层，没有展开项时禁用；"刷新"重读根目录并重取已展开的目录。
- 某一层读取失败时，那一行显示"读取失败"（警告色），不自动重试，等用户刷新。

## 抽屉

- 两种类型：文件预览与实时日志。
- 打开时右滑入场，背板点击、关闭按钮、Esc 都关闭；焦点移到对话框本身，关闭后回到触发元素。
- 文件预览：标题是文件名，副标题是完整路径与大小；正文等宽、可换行；底部动作"作为日志"切到日志抽屉。
- 日志抽屉：进入即读一次 `server.log_tail`，之后每 2.5 秒轮询；隐藏窗口或抽屉关闭时停止。
- 跟随逻辑：默认跟随到底部；用户向上滚动超过 40px 自动暂停并在底部显示"已暂停跟随"；点"继续跟随"滚到底部；日志为空时显示占位而不是空白。
- 读取失败时保留上一次内容并在底部状态写错误，不清屏。

## 轮询与状态

- 观测页每 4 秒刷新指标与实验；连续失败指数退避到 30 秒，恢复后回到 4 秒。
- 页面隐藏时停止所有计时器，恢复可见时立即刷新一次；仍使用 `window.setTimeout`，不用 rAF。
- 手动刷新重置退避、立即请求，并静默刷新当前文件目录。
- 顶部状态条用于短期反馈（绑定成功、复制成功、错误），6 秒后自动消失，不堆积。
- 绑定/解绑/切换服务器会清空实验选择、进度缓存、历史采样和抽屉内容。
- 报错必须说清发生过什么。单次 ssh 的输出上限（2 MB）按满额载荷留足：读日志会带回 256 KB 尾部，base64 后约 350 KB，所以上限一旦比载荷小，进程会被自己中途 kill，拿到的只有空 stderr，界面就只剩一句"退出码 -1，没有输出"。真被截断时说"远程返回过大"，没有退出码时说"被异常终止"，不硬报 -1。

## 响应式

- 宽度大于 980px：左栏 310–370px（实验列表在上、文件在下），检查器占剩余宽度并跨两行。
- 小于 980px：单列，按实验列表 → 检查器 → 文件堆叠；实验列表最高 42vh 内部滚动，空检查器隐藏。
- 小于 720px：绑定条换行，解绑按钮与刷新分开，KPI 两列（磁盘卡跨两列），抽屉占满宽度，文件树内部滚动高度收到 264px（原来在这里放开高度，长目录会把页面拉成几屏）。
- 任何断点下正文不小于 11px，标签不小于 10px，按钮触控高度不小于 30px。

## 约束

- RPC 名称保持不变：`server.metrics`、`server.experiments`、`server.progress`、`server.files`、`server.read_text`、`server.log_tail`，以及管理页的 `server.list` / `server.roots.*` / `ssh.*`。
- 不引入外部字体、图标库或构建步骤；图标一律内联 SVG。
- 面板仍在 `torra-ui` 沙箱帧里，没有 fetch、没有 Node；复制命令使用 `navigator.clipboard`，失败时回退到隐藏 textarea + `execCommand`。
- 深浅色都由宿主 `data-theme` 驱动，不在 JS 里读主题。
