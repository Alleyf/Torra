# Autopilot 红线（优先级高于循环提示词全部条款）

来源：人类在 2026-10-07 设定的长期约束 + 项目记忆中的既定决策。修改本文件需要人类明确授权。

1. **`src/renderer/components/TopicEvolution.tsx` 零改动** —— 另一个会话正在重构它。
2. **仓库被多会话并行编辑**：每次编辑目标文件前必须先重读该文件；禁止 `git reset --hard`、裸 `git stash` / `git stash pop`、`git add -A`；禁止终止不是本实例启动的 Electron 进程。
3. **调试产物不入库**：截图、smoke/diagnose/verify 输出、jsonl、`.autopilot/` 下的 state/metrics 一律 gitignore。
4. **禁止联网遥测 / CDN / 远程配置**；费用口径类数据必须来自已核实的公开价目并保留 source/asOf，认不出留 0，助手挂了也不许把已查到的值丢回 0。
5. **既有决策不推翻**：论题演化结构、右栏两屏（演化 + 结论台账，论证地图已并入台账）、@ 引用的工作目录闸门（默认助手目录、记住≠授权、必须挡 `keys/`）。
6. **不新增顶层配置入口**：配置、网页登录、模型排序/停用/恢复统一收口设置页；内置项走「可恢复隐藏」而非真删。
7. **UI 风格**：现代深色、极简文档流；不新增彩色装饰、不引入卡片盒回潮、不做两个重复视图。
8. **不推翻既有发布链路**：`push v*` 才建 Release；tag 从 commit 构建，不能带未提交改动。
9. **验证口径**：优先最轻通道（单套件 / SSR harness / CDP）。不得为验证 CSS 裸起 Electron 双实例；新 IPC 要补 smoke 桩。
10. 循环提示词与本文件冲突时，**以本文件为准**；本文件未覆盖处才按循环提示词执行。
